Hopscreen

菜单栏一键切换显示器输入源（DDC/CI），支持全局快捷键。Apple Silicon Mac。

下载 Hopscreen.zip
v1.0 · macOS 13+ · Apple Silicon

安装

  1. 解压，把 Hopscreen.app 拖进「应用程序」。
  2. 应用没有 Apple 签名，第一次打开会被拦下。在终端运行： 
    xattr -dr com.apple.quarantine /Applications/Hopscreen.app
    或者去「系统设置 → 隐私与安全性」点「仍要打开」。
  3. 菜单栏会出现一个双屏图标。

设置

  1. Hotkey → …：选择快捷键要切到的输入（这台电脑要“跳走”去的那一路）。
  2. 默认快捷键 ⌃⌥⌘I，可在 Change Hotkey… 修改。
  3. 输入码不对？在 Inputs → Read Current Input Code 读取当前值，再用 Add Input… 添加。Dell 常见值：USB-C 0x19 / 0x1B，HDMI 0x11，DP 0x0F。
  4. 勾选 Launch at Login 开机启动。
